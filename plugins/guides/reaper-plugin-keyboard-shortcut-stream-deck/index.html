Emelowsky Plugins / Guides

Put your favourite plugins on keyboard shortcuts, toolbar buttons or a Stream Deck in REAPER

There are plugins you put on almost every track: your go-to EQ, the compressor you trust, a de-esser on every vocal. Reaching for the mouse, opening a window and searching for them a hundred times per mix is time you could spend listening.

REAPER is built around actions - anything that is an action can go on a keyboard shortcut, a toolbar button, a MIDI control or a Stream Deck key. The trick is getting each plugin to be an action.

One action per plugin

Plugin Shelf for REAPER gives every plugin and FX chain on your shelf its own REAPER action. Assign it in the Action List like any other action:

  • A keyboard shortcut for your favourite EQ or compressor
  • Toolbar buttons for the plugins you use on every mix
  • MIDI controller buttons or Stream Deck keys for whole FX chains
  • Quick Switch: hold a key and type two digits to jump between shelf categories
  • Search by word fragments when the plugin is not on a key yet

A tip: start with five actions - your EQ, compressor, de-esser, reverb send chain and limiter. Within a week you will not want to go back.
