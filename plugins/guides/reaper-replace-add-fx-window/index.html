Open a visual plugin shelf instead of REAPER's Add FX window

The FX button on a track is probably the button you press most often in REAPER. It opens the Add FX window: a list of every plugin you own, sorted into folders. With a few hundred plugins, that list gets long, and the plugin you want is often a scroll and a search away.

REAPER's FX browser is flexible - you can make your own folders and favourites - but it stays a list of names. Many engineers think in pictures: the blue EQ, the vintage compressor with the big VU meter.

The shelf behind the FX button

Plugin Shelf for REAPER comes with Plugin Shelf Override: once it is on, REAPER opens the shelf instead of the Add FX window. Your plugins appear as tiles with icons, in your own categories, and one click puts the plugin on the track.

  • Your usual way of adding FX now opens the shelf
  • Over 4000 plugin icons from 130+ developers; missing one? capture it from the plugin window
  • Search by word fragments in any order: "comp air" finds AIR Compressor
  • FX chains and plugins with presets on the same shelf
  • Turn the override off any time to get REAPER's own window back

The free demo has no time limit - try it on a real mix and keep the window you like better.
